NHL Final Four Blueprint: Performance, Not Size, Defines Deep Playoff Runs

The four remaining teams share a clear on-ice profile: they control the scoring battle, limit dangerous chances, get above-average goaltending and create more takeaways. But their roster profiles are less uniform, suggesting there is no single age-or-size formula behind a deep run.

Key findings

What all four teams have in common

Start with the combined final-four takeaway, then use the tabs to see each team's standout strengths in a more digestible way.

7

Save percentage

The final four posted a 91.7% save percentage, +2.0 percentage points above the playoff-team average.

Why this matters

  • Scoring: The final four averaged 3.46 goals per game, versus 2.73 across playoff teams.
  • Defence: They allowed 2.28 goals per game, 0.71 fewer than the playoff-team average.
  • Danger suppression: They allowed only 1.10 high-danger xG and 3.38 high-danger shots per game.
  • Pressure: They averaged 5.03 takeaways per game, compared with 4.72 across playoff teams.
  • Roster caveat: Three of the four are shorter and lighter than the playoff-team average, but only Montreal is younger, suggesting there is no single age-or-size blueprint for a deep playoff run.

Methodology

How the analysis works

This page combines the final-four performance blueprint with a light-touch roster profile to show what these teams are doing well and whether they also share a similar build.

  • Performance view: The on-ice analysis is based on MoneyPuck playoff team data across all situations.
  • Comparison point: Each final-four team is measured against the average of all playoff teams, not against one another alone.
  • Shared-trait rule: A metric only appears in the combined final-four table when all four teams were better than the playoff-team average.
  • Roster profile: Age, height and weight are included as supporting context using NHL roster data.
  • Main takeaway: The strongest common thread is performance execution — not a single age, height or weight blueprint.
